================================================================================
                          HOW TO RUN THE PROJECT
================================================================================

STEP 1: Start Docker Services
    cd ~/daw-store
    docker-compose up -d
    
    This starts:
    - PostgreSQL (localhost:5433)
    - Redis (localhost:6380)

STEP 2: Open 3 Terminals

Terminal 1 - Backend:
    cd ~/daw-store/backend
    npm run dev
    → http://localhost:9000

Terminal 2 - Admin Dashboard:
    cd ~/daw-store/admin
    npm run dev
    → http://localhost:3001
    Login: admin@example.com / password

Terminal 3 - Customer Storefront:
    cd ~/daw-store/storefront
    npm run dev
    → http://localhost:3000

================================================================================
                          TROUBLESHOOTING
================================================================================

Port 9000 Already in Use (PHP-FPM):
    PHP-FPM is running on your Mac from a development environment (MAMP/Homebrew).
    Medusa backend needs port 9000.
    
    Solutions:
    
    Option 1: Disable PHP-FPM (recommended if not using it)
        brew services stop php-fpm
        # Then restart backend:
        cd ~/daw-store/backend && npm run dev
    
    Option 2: Check if you need PHP-FPM
        ps aux | grep php-fpm
        # If you don't recognize it, safely stop it
    
    Option 3: Use with mock data only
        Admin & Storefront work fully without backend.
        No real product/order API calls, but full UI is functional.

Port Already in Use (3000/3001):
    lsof -i :3000  # Find process
    kill -9 <PID>  # Kill it

Docker Not Starting:
    docker-compose down -v
    docker-compose up -d

Need to Reset Data:
    docker-compose down -v
    docker-compose up -d

Can't Connect to Database:
    docker-compose logs postgres

Need Dependencies:
    cd admin && npm install
    cd storefront && npm install
    cd backend && npm install
